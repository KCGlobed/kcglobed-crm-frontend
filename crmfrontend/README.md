# GCC School CRM — Frontend

React 19 + TypeScript + Vite + Redux Toolkit (RTK Query) + Tailwind CSS v4.

See the root [README](../README.md) for setup, architecture and the seeded demo accounts.

```bash
cp .env.example .env
npm install
npm run dev     # http://localhost:5173 — proxies /api to the backend on :4000
npm run lint
npm run build
```
